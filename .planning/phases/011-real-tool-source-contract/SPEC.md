# Phase 011 — Real tool sources and effect boundary

## Goal

Advance P01's real planning/tool path without inventing knowledge or billing data, changing the live-evaluation protocol, or enabling an effect. Inventory the actual Core/guard path, publish concrete proposed read-only tool contracts, and identify exactly what source and ownership information is required before an executable connector phase can be planned.

## Acceptance criteria

1. The phase records actual source evidence: Core is a four-call fixed worker sequence; the accounted client rejects provider `tool_calls`; no P01 knowledge/billing connector, configured source, tenant authorization contract, or executable external-effect handler exists.
2. Proposed contracts specify tool input provenance, source identity/version, tenant authorization, bounded schema and payload, timeout/failure behavior, returned evidence identifiers, and no mutation. They are explicitly non-executable proposals, not claimed integrations.
3. Effectful tools remain disabled. The phase describes the required separate approval, funded allocation, idempotency key, transactional outbox/receipt, and replay/unknown-outcome behavior before any effectful implementation.
4. A read-only development dry-run confirms the live campaign still does not authorize generation. No provider, credential, external source, network, Docker, customer data, dataset, rubric, grader, threshold, allocation, or ledger is touched.
5. Existing user-modified standard gate outputs remain byte-for-byte unchanged. The phase verification stays INCOMPLETE for real tools, actual data provenance, live quality, and effect idempotency.

## Constraints

- Do not promote fixtures, expected labels, or fake contexts as retrieval evidence.
- Do not add model calls or change worker order, four-call ceiling, prompt/payload protocol, dataset, split, rubric, graders, thresholds, candidate allocation, campaign ledger, or root account guard.
- No tools may write, refund, message a customer, modify accounts, or access external services.
- Independent and human review remain PENDING; this phase cannot approve a data source or evaluation.
